# Telegram News Analyzer

Приложение для анализа новостей в Telegram-каналах и поиска похожих статей между каналами.

## Описание

Это приложение позволяет:
1. Загружать .docx файл с заголовками и ссылками на новости
2. Выбирать диапазон дат для анализа
3. Автоматически анализировать и сравнивать новости между каналами
4. Находить похожие новости с учетом синонимов и перефразирования
5. Экспортировать результаты в Excel

## Требования

- Python 3.12
- Зависимости из requirements.txt

## Установка

1. Клонируйте репозиторий:
```
git clone <URL репозитория>
cd TgNewsAnalyzer
```

2. Создайте виртуальное окружение:
```
python -m venv .venv
```

3. Активируйте виртуальное окружение:
   - Windows:
   ```
   .venv\Scripts\activate
   ```
   - macOS/Linux:
   ```
   source .venv/bin/activate
   ```

4. Установите зависимости:
```
pip install -r requirements.txt
```

## Настройка Telegram API

Для работы с Telegram API необходимо получить собственные API_ID и API_HASH:

1. Перейдите на [my.telegram.org](https://my.telegram.org/)
2. Войдите в аккаунт Telegram
3. Выберите "API development tools"
4. Заполните форму (можно указать любое имя приложения)
5. Скопируйте полученные API_ID и API_HASH
6. Создайте файл `config.py` на основе `config.example.py` и вставьте в него полученные значения

> **Важно**: Файл `config.py` содержит чувствительные данные и добавлен в `.gitignore`. Не публикуйте его в публичных репозиториях.

## Использование

1. Запустите приложение:
```
python TgNewsAnalyzer.py
```

2. Нажмите кнопку "Загрузить Word-файл" и выберите .docx файл с заголовками и ссылками на новости
3. Выберите диапазон дат для анализа
4. Нажмите "Запустить анализ"
5. После завершения анализа, нажмите "Экспорт в Excel" для сохранения результатов

## Формат .docx файла

Файл должен содержать заголовки и ссылки на новости в формате:
```
Заголовок новости (https://t.me/zakonkz/12345)
```

## Примечания

- При первом запуске приложение попросит авторизоваться в Telegram через номер телефона и код подтверждения
- Порог схожести для определения похожих новостей установлен на 70%
- Приложение использует модель русского языка spaCy для анализа текста
